Distribution layer for Booxtra — connects the MCP server to Claude, Hermes, Gemini, ChatGPT, and Goose.

## Structure

- `references/` — the **only** source of truth for accounting and tax knowledge (curated markdown, PR-reviewed)
- `base-prompt.md` — canonical base prompt delivered as server instructions to all hosts
- `skills/` — orchestration logic (no facts)
- `targets/` — per-host connection artifacts (generated by build, Plan 3)
- `scripts/` — build pipeline (Plan 2)

## Development

```bash
npm install
npm run validate    # validate references frontmatter + Unicode
npm test            # run validate.mjs test suite
npm run build       # build all target artifacts (requires Plan 2)
```

## Adding or editing knowledge

1. Edit files in `references/` only. Never edit generated artifacts in `dist/`.
2. Bump `version` in frontmatter when content changes.
3. Open a PR — requires review from `@booxtra/knowledge-owners`.
4. CI runs `validate.mjs` on every PR automatically (Plan 2).
